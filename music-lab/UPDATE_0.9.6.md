# Music Lab Alpha 0.9.6 — Problem Engine & Quiz UI (1차)

## 새로운 문제 연구실
- 대시보드와 좌측/하단 메뉴에서 **문제 연구실**로 진입.
- 6개 문제 분야: 화성학, 기타 코드, 기타 지판, 기타 악보 읽기, 청각훈련, 리듬.
- 난이도 1~3, 문항수 5/10/20 선택.
- 학습(즉시 해설), 실전(종료 후 채점), 오답 복습(틀린 분야에서 새로 출제).
- 각 문제는 음악 규칙·결정적 시드로 브라우저에서 생성. 문제 이미지·오디오 파일 개별 저장 없음.
- 사용한 시드·생성기 버전·정답 여부·선택지·날짜를 기기별 학습 기록에 저장; JSON 백업 및 복원에 포함.
- 최근 문제 서명 기준 중복 회피. 제한된 범위가 소진되면 재출제를 허용.
- 기타 악보 퀴즈는 **단음 위치 읽기**로 시작하며, 기존 기타 초견 메뉴의 멜로디 악보 연습 기능은 별도로 유지.

## 기존 기능
- Alpha 0.9.5의 코드 사전, 실제 기타 지판, 크로매틱, 코드 스튜디오, 반주, 기타 모델링 음색, 기존 청음, 화성학, 보컬 기능과 관련 localStorage 키를 유지.
- 0.9.6 JS/CSS 버전 및 서비스워커 캐시 버전 갱신.

## UI 협업
- 이번 단계는 **문제 연구실의 설정/풀이/결과 UI**만 우선 새로 구성.
- 다음 단계에서 사용자 피드백을 받아 이 화면의 버튼·글꼴·색상·위치 등을 한 화면씩 조정할 수 있음.
